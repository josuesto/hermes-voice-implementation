# Security Policy

## Current status

This repository is pre-release and documentation-only. There is no working implementation, supported version, or production security claim. The threat model and security controls remain subject to feasibility evidence and checkpoint review.

## Reporting a vulnerability privately

If GitHub private vulnerability reporting is available for this repository, use **Security → Report a vulnerability** to open a private GitHub Security Advisory. Do not disclose exploitable details in a public issue or pull request.

If private reporting is not available, contact the repository owner through a private contact method listed on their GitHub profile. If no private method is available, open a minimal public issue requesting a private security contact without including vulnerability details.

Never include credentials, tokens, private links, provider or account data, IP or MAC addresses, Telegram details, personal machine inventory, Codex prompts or task content, logs containing sensitive data, transcripts, or audio in any issue, pull request, discussion, or evidence attachment.

Please include a concise impact summary, affected design or future component, reproduction conditions, and a proposed mitigation when possible. Reports will be assessed against the active checkpoint and the project's current pre-release status.
